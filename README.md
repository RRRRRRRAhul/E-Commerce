# E-Commerce Full Stack Application

A modern full-stack E-Commerce application built with React, Redux Toolkit, Django REST Framework, and PostgreSQL. This project includes product management, cart system, order management, payment flow, and an admin dashboard with analytics.

## Order Status Workflow

The application supports secure order state transitions:

- PENDING → CONFIRMED / CANCELLED
- CONFIRMED → SHIPPED / CANCELLED
- SHIPPED → DELIVERED

Invalid status transitions are restricted from both backend and frontend.
